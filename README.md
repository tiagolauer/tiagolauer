## Selected work

### [OwlSQL](https://github.com/tiagolauer/OwlSQL)

**Compile-time typed SQL for TypeScript.**

OwlSQL keeps raw SQL while inferring result and parameter types without introducing an ORM, query-builder DSL, codegen pipeline, or runtime SQL parser.

I work on its type-level SQL parsing, schema inference, driver abstractions, explicit `Result`-based API, documentation, CI, package design, and release workflow.

`TypeScript` · `SQL` · `Type Systems` · `Developer Tools`

### [pieces-to-agents](https://github.com/tiagolauer/pieces-to-agents)

**Safe, local-first context for coding agents.**

A developer tool that turns Pieces Long-Term Memory into repository-scoped context for agentic development workflows, with a strong focus on redaction, privacy boundaries, and practical interoperability with coding agents.

`TypeScript` · `Node.js` · `MCP` · `AI Agents` · `Local-first`
